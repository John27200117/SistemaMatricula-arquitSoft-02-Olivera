# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como apoderado, quiero registrar y actualizar mis datos y los del estudiante, para mantener la información necesaria para su matrícula. |
| HU02 | Como apoderado, quiero consultar los requisitos, fechas y vacantes de matrícula, para preparar mi solicitud. |
| HU03 | Como apoderado, quiero registrar una solicitud de matrícula y adjuntar los documentos requeridos, para realizar el trámite de manera virtual. |
| HU04 | Como apoderado, quiero consultar el estado de mi solicitud y recibir notificaciones, para conocer su avance y atender las observaciones. |
| HU05 | Como apoderado, quiero corregir los datos y documentos observados, para completar los requisitos de matrícula. |
| HU06 | Como apoderado, quiero descargar la constancia de matrícula cuando sea confirmada, para contar con un comprobante del proceso. |
| HU07 | Como personal administrativo, quiero revisar las solicitudes y documentos con apoyo de IA, para identificar información incompleta o inconsistente. |
| HU08 | Como personal administrativo, quiero registrar observaciones y confirmar o rechazar solicitudes según los requisitos y vacantes disponibles, para resolver el proceso de matrícula. |
| HU09 | Como personal administrativo, quiero gestionar periodos académicos, grados, secciones y vacantes, para organizar la matrícula escolar. |
| HU10 | Como personal administrativo, quiero gestionar cursos, docentes y sus asignaciones, para organizar las actividades académicas. |
| HU11 | Como docente, quiero consultar mis cursos y estudiantes asignados, para organizar el seguimiento de mis clases. |
| HU12 | Como docente, quiero registrar la asistencia de mis estudiantes, para realizar el seguimiento de su participación. |
| HU13 | Como docente, quiero registrar calificaciones y observaciones académicas, para comunicar el desempeño de mis estudiantes. |
| HU14 | Como estudiante, quiero consultar mi matrícula, cursos, asistencia y calificaciones, para conocer mi situación académica. |
| HU15 | Como apoderado, quiero consultar la asistencia, calificaciones y observaciones del estudiante a mi cargo, para acompañar su aprendizaje. |
| HU16 | Como integrante de la dirección, quiero consultar reportes y estadísticas de matrícula, asistencia y desempeño académico, para apoyar la toma de decisiones. |
| HU17 | Como administrador del sistema, quiero gestionar cuentas, roles y permisos, para controlar el acceso a las funciones e información. |
| HU18 | Como administrador del sistema, quiero configurar los parámetros generales de la plataforma, para adecuar su funcionamiento al periodo académico. |
| HU19 | Como apoderado, quiero realizar consultas a un asistente virtual sobre requisitos y pasos de matrícula, para recibir orientación durante el trámite. |
